Google Photos accounts

Add an account using its email address. Each account has its own browser profile and folder inside your selected backup folder.

Select Google sign-in for an account to open the browser on Unraid in a popup. After signing in, select Start backup; the portal closes the sign-in browser automatically. Use Close sign-in to close it without starting a backup. The existing account keeps its files in the main folder. Only add it again if you want a separate download from the beginning.

Settings and history

Schedule

Weekdays

Free-space reserve

The reserve applies to the filesystem holding the backup folder. Backup pauses on low space; large files may still need more space.

Notifications (optional)

Saving a URL enables backup failure notifications. Only the result and new file count are sent, never email addresses, filenames or photos. Clear the URL to disable notifications.

Backup check

Checks detect missing and empty catalog files. They do not prove that every Google file has been downloaded or that file contents are intact.

Coverage by year and album

Coverage compares the latest Google index with local files. Shared-album or archived items outside the main library may appear missing. It is not proof of full coverage.

File contents and checksums

The first check records a SHA-256 baseline; later checks show changes. Supported photos are decoded and videos checked with ffmpeg (up to five minutes per file). Unknown formats and timeouts are unverified. Checking can take a long time and changes no media files.

Duplicates

Only identical bytes are grouped. Album hard links are excluded. The report shows up to 200 groups and 20 locations per group. No files are deleted.
